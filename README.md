# Venstack 🇻🇪

> **El talento tech de Venezuela, reunido en un solo lugar.**  
> Plataforma y red profesional para talento venezolano en **Software**, **UI/UX**, **Inteligencia Artificial** y **Ciberseguridad**.

![Venstack Banner](/public/img/venstack.png)

---

## 🚀 Características Principales

- **Directorio de Profesionales Tech**: Catálogo de talento venezolano con filtros por disciplina, stack técnico, nivel (incluyendo *Junior Friendly*) y ciudad (Caracas, Valencia, Maracaibo, Lechería, Mérida, etc.).
- **Estructura de Compensación Dual**: Transparencia salarial con rangos en tarifas mensuales (`$/mes`) para contratos full-time y tarifas por hora (`$/hora`) para modalidades freelance.
- **Conectividad & Setup Eléctrico Verificado**: Badges de verificación técnica que confirman sistemas de respaldo eléctrico (inversor/UPS) e internet de fibra óptica.
- **Bolsa de Empleos & Micro-Bounties**: Ofertas de trabajo remotas con pagos directos en USDT, Zinli y plataformas globales.
- **Squads Comunitarios**: Equipos guiados por mentores Seniors para desarrollar proyectos reales de código abierto con certificados de *Proof of Work*.
- **Autenticación con Firebase**: Sistema de registro e inicio de sesión integrado con Firebase Auth (Correo/Contraseña, Google y GitHub).
- **Diseño Ultra-Premium**: Estética minimalista inspirada en los estándares de Apple, con transición cinematográfica de onboarding, dock flotante nativo para móviles y micro-interacciones fluidas.

---

## 🛠️ Stack Tecnológico

- **Frontend**: React 18, Vite
- **Estilos**: Vanilla CSS con Sistema de Diseño de Tokens Apple
- **Iconografía**: Lucide React
- **Backend / BaaS**: Firebase (Authentication, Firestore Database, Analytics)

## 💻 Instalación y Desarrollo Local

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/conecta2developers-bit/venstack.git
   cd venstack
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo**:
   ```bash
   npm run dev
   ```

4. **Compilar para producción**:
   ```bash
   npm run build
   ```
